# CoinQuest

Ứng dụng tiết kiệm tiền lẻ với Level, XP, Streak, VietQR và sao lưu JSON.

## Mở bằng GitHub Pages

1. Tạo repository `coinquest` trên GitHub.
2. Tải `index.html` và `.nojekyll` trong thư mục này lên thư mục gốc của repository.
3. Vào Settings → Pages → Build and deployment.
4. Chọn Source: Deploy from a branch; Branch: main; Folder: / (root); Save.
5. Mở đường dẫn website được GitHub Pages hiển thị khi triển khai xong.

Chỉ tải mã ứng dụng, không tải file backup JSON chứa dữ liệu cá nhân.
Dữ liệu ứng dụng được lưu ở trình duyệt mỗi thiết bị; không tự đồng bộ giữa máy tính và điện thoại.
Nếu chuyển từ bản HTML cục bộ, hãy xuất JSON rồi nhập lại ở website mới.
Cần mạng để tải TailwindCSS, confetti và ảnh VietQR.

Tài liệu: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
